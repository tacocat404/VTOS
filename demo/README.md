# 디자인 확인용 더미

**여기 있는 것은 전부 가짜입니다.** 사람 이름·기록·PRD 항목 모두 만들어낸 것입니다.
진짜 기록은 `members/` 와 `.team/` 에 있고, 이 폴더는 그것을 건드리지 않습니다.

## 왜 필요한가

혼자서 하루 만에 쌓은 기록으로는 확인할 수 없는 화면이 있습니다.

- 「22일째 방치된 질문」 — 시간이 필요합니다
- 「판단 변경」 — 앞선 결정을 뒤집은 적이 있어야 합니다
- 「초대 수락 대기」·「자동 기록 꺼짐」 — 사람이 여럿이어야 합니다
- 「PRD 추적률 86%」 — 병합을 거쳐야 생깁니다

## 다시 만들기

```bash
python tools/make_demo.py
```

날짜는 **실행 시각 기준 상대값**입니다. 고정 날짜를 박으면 며칠 뒤에 "300일째"가 됩니다.

## 열기

```bash
python -m http.server 8766 --directory demo
```

`file://` 로 열어도 됩니다.
